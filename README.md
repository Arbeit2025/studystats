# studystats（学習ログ分析レポート）

学習ログの CSV をアップロードすると、学習の傾向をまとめたレポートを表示する単一ファイル Flask アプリです。DB は使わず、アップロードされたファイルは保存しません（メモリ上でのみ処理します）。

## 機能

- CSV アップロード、またはテキストエリアへの貼り付けで分析
- 表示するレポート
  - 総学習時間
  - 学習した日数
  - 連続日数（最新の記録日から遡った streak）
  - 科目別の合計時間（CSS バーで可視化、割合つき）
  - 理解度（1〜5）の平均
  - 直近7日とその前7日の比較（差分と増減率）
  - 最も学習した科目などを含むサマリ文
- サンプル CSV のダウンロード（画面のリンクから）
- 不正な行はスキップして件数を表示
- アップロード上限 1MB

## CSV の形式

列は「日付, 科目, 学習分, 理解度」の4列です。ヘッダー行はあってもなくても構いません。

```csv
日付,科目,学習分,理解度
2026-10-31,数学,60,4
2026-10-31,英語,45,5
2026-10-30,数学,30,3
```

- 日付：`YYYY-MM-DD` または `YYYY/MM/DD`
- 学習分：正の数（分）
- 理解度：1〜5 の整数
- 文字コードは UTF-8（BOM 付き可）または Shift_JIS に対応

形式に合わない行はスキップされ、件数がレポートに表示されます。

## ローカル起動

```bash
pip install -r requirements.txt
python app.py
# http://127.0.0.1:5000
```

